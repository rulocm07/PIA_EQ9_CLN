# Glosario ubicuo
| Término | Definición de negocio |
|---|---|
| Habitación | Unidad de alojamiento reservable y ocupable. |
| Estándar | Hasta 2 adultos; tarifa base $1,200/noche. |
| Doble | Hasta 4 personas; tarifa base $1,800/noche. |
| Suite | Hasta 4 personas, sala y jacuzzi; $3,000/noche. |
| Temporada baja | Marzo-junio y septiembre-noviembre; tarifa base. |
| Temporada alta | Julio-agosto, diciembre y Semana Santa; incremento 35%. |
| Reserva | Apartado de habitación por fechas y huéspedes. |
| Disponibilidad | Habitaciones reservables para fechas específicas. |
| Garantía | Anticipo 50% o tarjeta en garantía. |
| Anticipo | Pago de 50% del total para confirmar. |
| Cancelación | Anulación previa a llegada, con política de reembolso. |
| No-show | Huésped no se presenta el día de llegada. |
| Check-in / Check-out | Entrada / finalización de estancia y liberación. |
| Early check-in | Entrada antes de las 15:00, con política antes de 12:00. |
| Late check-out | Salida después de 12:00. |
| Estancia | Periodo hospedado. |
| Cambio de habitación | Reubicación durante estancia. |
| Upgrade | Cambio voluntario a categoría superior pagando diferencia. |
| Salida anticipada | Fin antes de fecha reservada. |
| Consumo | Servicio/producto que genera cargo. |
| Folio | Cuenta de estancia con hospedaje y consumos. |
| Inspección exprés | Revisión aproximada de 5 minutos de frigobar/daños. |
| Limpieza | Preparación de habitación tras check-out. |
| Limpia/Inspeccionada | Habitación limpia y revisada, lista para asignarse. |
| Fuera de Servicio | Habitación no utilizable por avería/mantenimiento. |
| Overbooking | Sobreventa; meta y regla = 0. |
| Garantía incidental | $1,000 voucher de tarjeta o $500 efectivo para cargos potenciales. |
| Corte de Caja Diario | Reporte de ingresos efectivo/terminal/transferencias. |
| Folios Abiertos | Cuentas activas con cargos pendientes. |
| Ocupación diaria | Entradas, salidas y habitaciones fuera de servicio. |
| Administración | Autoriza operaciones sensibles y consulta reportes. |
